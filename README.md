### How to run the game
To see the game run, open the snake_runner_and_analysis.ipynb file, and then run the code cells from top to bottom in order. Make absolutely sure that the cells are run in descending order from the top of the file, otherwise unexpected behavior may occur. Make sure to have selected a Python kernel in order for the file to run properly.

### Navigating the .ipynb Notebook file

The first section of the file allows the user to play a single run of the game using each agent separately, while also providing a visual representation of each of those runs. This way the user can actually see how the various algorithms make the different snake agents behave, making it easier for the user to understand and then compare the performance of each agent without requiring the actual run data.

The latter section of the notebook is the data analysis section. It runs simulations of each of the agents 100 times and then records the data resulting from the simulations. Following that, the data is compiled into a bar graph, graphing the results so the user can see how each algorithm compares to the others, giving insight into the performance of the various algorithms with more certainty due to them being run 100 times.
